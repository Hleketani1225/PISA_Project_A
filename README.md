
# Project A: PISA 2022 Analysis

## Project objective
Investigate which school-level factors are most strongly associated
with student performance: school equipment, class size, and teacher
qualifications. Examine whether the relationships remain after
accounting for family background.

## Dataset
Source: OECD PISA 2022
Download page: https://webfs.oecd.org/pisa2022/index.html

## Project structure
- data: downloaded data files
- notebooks: Python notebooks
- README.md: project instructions

## How to run the analysis
1. Download the PISA data from the OECD.
2. Place the required data files in the data/ folder.
3. Open notebook PISA_Project_A_data_exploration.ipynb in Google Colab or Jupyter.
4. Install any required Python packages.
5. Run the notebook cells from top to bottom.
